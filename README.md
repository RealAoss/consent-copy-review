# Consent Copy Review

Review a consent screen for understandable choices, purpose, scope and withdrawal wording.

Copy the instructions in [SKILL.md](SKILL.md) into ChatGPT or Claude and supply the material you want reviewed. In an Agent Skills environment, install the folder with its original name.

## Example

A signup form asks users to accept all updates without describing what they receive.

Expected behavior: Ask which updates are optional and identify their purpose before drafting specific choices.
