# Consent Copy Review

List the decisions a reader is asked to make. Map each option to the stated use of their data or participation. Highlight bundled choices, unclear duration and consequences absent from the screen. Write a plain-language revision using only supplied facts. Flag product decisions that need an owner before final copy can be drafted.
